# หลักฐานหน้าอัปโหลด ChatGPT

ตรวจผ่านเบราว์เซอร์ที่ล็อกอินบัญชีผู้ใช้เมื่อ 19 พฤศจิกายน 2569:

- หน้า `https://chatgpt.com/plugins` มีเมนู “เพิ่ม” และตัวเลือก “อัปโหลดไฟล์เก็บถาวรของปลั๊กอิน”
- หน้า `https://chatgpt.com/skills` มีเมนู “เพิ่ม Skill” และตัวเลือก “อัปโหลดจากคอมพิวเตอร์”
- กล่องอัปโหลดระบุรองรับ `.zip`, `.skill` หรือ `SKILL.md` และขนาดสูงสุด 780 MiB ต่อไฟล์

รอบนี้ยังไม่ได้ส่งไฟล์ขึ้นบัญชีจริง จึงไม่บันทึกผลว่า Plugin/Skill ติดตั้งหรือสนทนา end-to-end สำเร็จ การทดสอบดังกล่าวเป็นขั้นตอนภายนอกที่ผู้ใช้ทำต่อได้จากไฟล์ใน `dist/`
