# สรุปการทำงาน TOR Expert Current Knowledge

เอกสารนี้อธิบายความคืบหน้าด้วยภาษาทั่วไปและจะอัปเดตเมื่อแต่ละช่วงเสร็จสิ้น

## การเผยแพร่ให้ผู้อื่นนำไปใช้

เพิ่มใบอนุญาต MIT ให้ผู้อื่นนำ Skill และโค้ดไปใช้ แก้ไข หรือแจกต่อได้ พร้อมแยก PDF และเนื้อหาจากหน่วยงานรัฐออกจากใบอนุญาตนี้อย่างชัดเจน ไฟล์ส่งมอบทั้ง 3 ชุดมีคำชี้แจงนี้แนบไปด้วย จึงไม่ทำให้ผู้ดาวน์โหลดเข้าใจผิดว่าเอกสารราชการถูกเปลี่ยนเป็น MIT

## จุดเริ่มต้น

โปรเจกต์เริ่มจากโฟลเดอร์ว่าง แชทเดิมเป็นเพียงการหารือแนวทางและไม่มีไฟล์ความรู้เดิมเหลืออยู่ จึงต้องสร้างทั้งผู้ช่วยและคลังเอกสารขึ้นใหม่จากแหล่งต้นทาง

## หลักที่ใช้

- ใช้เว็บไซต์ราชการเป็นแหล่งหลัก
- เอกสารที่ยังตรวจสถานะไม่ได้จะไม่ถูกใช้ตอบว่าเป็นกฎหมายปัจจุบัน
- แยกเอกสารเก่าออกจากคลังที่ใช้ทำงาน
- เก็บหลักฐานแหล่งที่มา วันที่ตรวจ และค่าแฮชของไฟล์ทุกฉบับที่ดาวน์โหลดได้

## ผลลัพธ์ที่ทำเสร็จ

- จัดทำทะเบียน 29 รายการ แยก Current, Amended, Superseded และ Unverified
- กู้คืน PDF ทางราชการ 18 ไฟล์ พร้อมตรวจว่าเปิดได้และบันทึกค่า SHA-256
- ยืนยันจากหน้าเอกสารจริงว่า ว714 แทน ว299, ว715 แทน ว298 และ ว755 แทน ว108/2563
- เพิ่ม ว777 ซึ่งออกภายหลังรายการตั้งต้นและกระทบการกำหนดระยะเวลายืนราคาใน TOR
- สร้างแนวทางตรวจ TOR และ Checklist 6 ชุด โดยติดป้ายว่าเป็นข้อเสนอแนะ ไม่ใช่ตัวบทกฎหมาย
- สร้าง ChatGPT Plugin และ Gemini CLI Skill จากแกนเดียวกัน
- สร้าง ZIP 3 ชุด โดย Gemini ZIP มีคลังความรู้รวมอยู่ภายใน
- ทดสอบอัตโนมัติ 18 รายการผ่านทั้งหมด และตัวตรวจมาตรฐาน Skill รายงานว่าใช้ได้

## ข้อจำกัดที่เปิดเผยไว้

มี 4 รายการสถานะ Current/Amended ที่ยังดาวน์โหลดไฟล์จริงไม่ได้ ได้แก่ ว753, ว1203, กฎกระทรวงฉบับหลัก พ.ศ. 2563 และฉบับที่ 2 พ.ศ. 2563 โดยเก็บลิงก์ทางการและสาเหตุไว้ใน Manifest แล้ว เอกสารที่ยืนยันสถานะไม่ได้ 3 รายการถูกกักไม่ให้ Skill ใช้เป็นหลักปัจจุบัน

## ผลกระทบต่อผู้ใช้

ตอนนี้ผู้ใช้สามารถติดตั้งผู้ช่วย TOR ใน ChatGPT หรือ Gemini CLI แล้วใช้ตรวจ TOR จากคลังเดียวกันได้ โดยระบบมีแนวป้องกันการอ้างหนังสือเวียนที่ถูกยกเลิกและระบุข้อจำกัดเมื่อหลักฐานไม่พอ

## รอบปรับปรุง 19 พฤศจิกายน 2569

- เพิ่มตัวอัปเดตคลังความรู้ที่ตรวจโดเมนราชการ, ลายเซ็น PDF, จำนวนหน้า และ SHA-256 ก่อนติดตั้ง
- หากมีไฟล์เดิม ระบบเก็บสำเนาไว้ใน `99_SUPERSEDED_ARCHIVE/updates` ก่อนแทนที่
- กู้คืน PDF ว753 สำเร็จ ทำให้ไฟล์ที่ตรวจแล้วเพิ่มจาก 18 เป็น 19 ไฟล์
- ปรับสถานะ SP-002 เป็น `AMENDED` และ OLD-570 เป็น `SUPERSEDED` ตามหลักฐาน gprocurement
- เพิ่มตัวตรวจ Plugin/Skill, ชุดประเมินคุณภาพ 5 กรณี และ GitHub Actions
- หน้า ChatGPT ตรวจแล้วว่ามีเมนูอัปโหลด Plugin และ Skill; การอัปโหลดจริงและการทดลองตอบในบัญชีผู้ใช้ยังเป็นขั้นตอนภายนอกที่ต้องทำต่อ
