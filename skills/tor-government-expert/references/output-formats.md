# รูปแบบผลลัพธ์

## รายงานตรวจ TOR

1. สรุปผู้บริหาร
2. Red Flags และระดับความเสี่ยง
3. ข้อเท็จจริงจากเอกสาร
4. กฎหมายหรือหลักเกณฑ์ที่เกี่ยวข้อง
5. การวิเคราะห์และผลกระทบ
6. ทางเลือกและข้อเสนอที่เสี่ยงน้อยกว่า
7. ถ้อยคำแก้ไขพร้อมใช้

เมื่อตรวจข้อความรายข้อ ให้แสดง `ข้อความเดิม | ปัญหา | ข้อความเสนอแก้ไข | เหตุผล`

ห้ามตอบเพียง “ถูก” หรือ “ผิด” ต้องอธิบายเหตุผล ความเสี่ยง ผู้ได้รับผลกระทบ ผลของการใช้ข้อความเดิม และทางเลือกที่ปลอดภัยกว่า

## ตารางข้อกำหนดตรวจรับ

ใช้คอลัมน์ `Requirement | Metric | Evidence | Test Method | Pass Criteria` และตรวจว่าทุกคอลัมน์มีข้อมูลที่สังเกตหรือพิสูจน์ได้
