# Checklist ตรวจ TOR

> สถานะ: แนวทางวิเคราะห์/ข้อเสนอแนะ ไม่ใช่กฎหมาย

- [ ] ชื่อโครงการสอดคล้องกับเนื้อแท้ของงาน
- [ ] ความจำเป็น วัตถุประสงค์ และผลลัพธ์เชื่อมโยงกัน
- [ ] ขอบเขตงานและผลส่งมอบครบถ้วน ไม่ซ้ำหรือขัดกัน
- [ ] ทุก Requirement มี Metric, Evidence, Test Method และ Pass Criteria
- [ ] คุณสมบัติผู้ยื่นข้อเสนอจำเป็นและได้สัดส่วน
- [ ] เงื่อนไขผลงาน บุคลากร และหนังสือรับรองไม่จำกัดการแข่งขันเกินจำเป็น
- [ ] ระยะเวลา งวดงาน งวดเงิน และการตรวจรับสอดคล้องกัน
- [ ] เงื่อนไขรับประกัน SLA การแก้ไข และค่าปรับวัดผลได้
- [ ] แบบ สเปก ปริมาณ และเอกสารอ้างอิงใช้เลขฉบับเดียวกัน
- [ ] งาน IT ครอบคลุมข้อมูล ความมั่นคงปลอดภัย สิทธิในผลงาน และ Exit Plan
- [ ] มีแผนบริหารการเปลี่ยนแปลงและการขยายเวลา
- [ ] ฐานกฎหมายทุกฉบับผ่านการตรวจสถานะ
