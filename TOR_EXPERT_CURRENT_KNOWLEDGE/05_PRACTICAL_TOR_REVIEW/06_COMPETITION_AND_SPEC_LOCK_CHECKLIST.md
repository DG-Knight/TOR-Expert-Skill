# Checklist การจำกัดการแข่งขันและการล็อกสเปก

> สถานะ: แนวทางวิเคราะห์/ข้อเสนอแนะ ไม่ใช่กฎหมาย

ตรวจแต่ละข้อโดยถามว่า “จำเป็นต่อผลลัพธ์หรือความปลอดภัยหรือไม่ มีทางเลือกที่จำกัดการแข่งขันน้อยกว่าหรือไม่ และมีหลักฐานอะไร”

- [ ] Direct lock: ระบุยี่ห้อ รุ่น แหล่งผลิต หรือสิทธิเฉพาะ
- [ ] Datasheet lock: เรียงถ้อยคำหรือลำดับคุณลักษณะตรงเอกสารผู้ผลิตรายเดียว
- [ ] Numerical lock: ช่วงตัวเลขแคบหรือหลายตัวเลขประกอบกันจนเหลือรายเดียว
- [ ] Certification lock: เรียกใบรับรองเฉพาะที่ไม่สัมพันธ์กับความเสี่ยง
- [ ] Dealer lock: บังคับหนังสือแต่งตั้งหรือลำดับตัวแทนโดยไม่จำเป็น
- [ ] Experience lock: มูลค่า จำนวนสัญญา หรือช่วงเวลาสูงเกินสัดส่วน
- [ ] Personnel lock: คุณวุฒิ ใบอนุญาต หรือจำนวนบุคลากรเกินความจำเป็น
- [ ] Geographic lock: จำกัดสถานที่ตั้งหรือประสบการณ์เฉพาะพื้นที่
- [ ] Compatibility lock: อ้างความเข้ากันได้โดยไม่เปิดมาตรฐานหรืออินเทอร์เฟซ
- [ ] POC/Demo lock: กำหนดการสาธิตที่ใช้ต้นทุนสูงหรือเอื้อระบบเดิม
- [ ] Scoring lock: คะแนนพิเศษผูกกับคุณลักษณะของรายใดรายหนึ่ง
- [ ] Ecosystem lock: ผูกบริการ อะไหล่ ข้อมูล หรือ License กับผู้ขายเดิม
- [ ] Bundling lock: รวมงานต่างตลาดจนคู่แข่งที่ทำส่วนหลักเข้าไม่ได้
