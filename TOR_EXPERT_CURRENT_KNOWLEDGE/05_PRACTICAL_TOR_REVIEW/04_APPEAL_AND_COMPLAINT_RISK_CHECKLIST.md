# Checklist ความเสี่ยงร้องเรียนและอุทธรณ์

> สถานะ: แนวทางวิเคราะห์/ข้อเสนอแนะ ไม่ใช่กฎหมาย

- [ ] เงื่อนไขสำคัญมีเหตุผลที่เชื่อมกับผลลัพธ์และความเสี่ยงของงาน
- [ ] ผู้ประกอบการหลายรายในตลาดสามารถเข้าแข่งขันได้จริง
- [ ] ระยะเวลาจัดทำข้อเสนอเหมาะกับความซับซ้อนและหลักฐานที่เรียก
- [ ] ไม่มีเงื่อนไขเปลี่ยนสาระสำคัญหลังยื่นข้อเสนอ
- [ ] หลักเกณฑ์ผ่าน/ไม่ผ่านและการให้คะแนนตีความได้แบบเดียว
- [ ] เอกสาร ตัวอย่าง POC และ Demo ที่เรียกมีความจำเป็นและต้นทุนได้สัดส่วน
- [ ] คำชี้แจงและการแก้ TOR ถูกสื่อสารอย่างเท่าเทียม
- [ ] เหตุผลการตัดสินใจอ้างข้อเท็จจริงและหลักเกณฑ์ที่ประกาศไว้
- [ ] แยกอุทธรณ์ผลจัดซื้อจัดจ้างออกจากการโต้แย้งผลประเมินผู้ประกอบการ
- [ ] ตรวจวันมีผลและบทเฉพาะกาลของกระบวนการอุทธรณ์ที่ใช้
