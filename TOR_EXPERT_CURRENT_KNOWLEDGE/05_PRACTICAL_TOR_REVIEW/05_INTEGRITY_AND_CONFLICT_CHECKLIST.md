# Checklist ความเสี่ยงทุจริตและผลประโยชน์ทับซ้อน

> สถานะ: แนวทางวิเคราะห์/ข้อเสนอแนะ ไม่ใช่กฎหมาย

- [ ] ความต้องการมีอยู่จริงและพื้นที่/ระบบรองรับพร้อม
- [ ] ปริมาณและงบประมาณมีหลักฐานและสมมติฐานตรวจสอบได้
- [ ] ผู้จัดทำ TOR ผู้ให้ข้อมูลตลาด และผู้เสนอราคาไม่มีผลประโยชน์ทับซ้อนที่ไม่เปิดเผย
- [ ] ไม่มีการคัดลอกคุณลักษณะของผู้ขายรายเดียวเกินความจำเป็น
- [ ] ตรวจความสัมพันธ์ ผู้แทนจำหน่าย และแหล่งที่มาของหนังสือรับรอง
- [ ] ราคาและต้นทุนตลอดอายุใช้งานครอบคลุมค่าบำรุง License และการย้ายระบบ
- [ ] การแบ่งงวด การตรวจรับ และการจ่ายเงินไม่เปิดช่องรับมอบของไม่ครบ
- [ ] การเปลี่ยนแปลงสัญญามีเหตุผล ขอบเขต และร่องรอยอนุมัติ
- [ ] ข้อมูลการตัดสินใจเพียงพอให้ผู้ตรวจสอบภายนอกติดตามได้
- [ ] มีมาตรการจัดการ Single-source และ Vendor/Ecosystem Lock-in
